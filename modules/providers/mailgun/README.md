# Mailgun Provider

Email provider using [Mailgun](https://mailgun.com) for transactional email delivery.

## Configuration

| Field    | Type   | Required | Description                              |
|----------|--------|----------|------------------------------------------|
| `apiKey` | string | Yes      | Your Mailgun API key                      |

## Usage

Configure the provider with your Resend API key from the [Mailgun dashboard](https://app.mailgun.com/settings/api_security).

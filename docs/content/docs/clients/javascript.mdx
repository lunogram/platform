# JavaScript SDK

The Lunogram JavaScript SDK provides user identification and event tracking for both browser and Node.js environments.

## Installation

Install the SDK using your preferred package manager:

### npm

```bash
npm install @lunogram/js-sdk
```

### Yarn

```bash
yarn add @lunogram/js-sdk
```

### pnpm

```bash
pnpm add @lunogram/js-sdk
```

### Script Tag (CDN)

For quick prototyping or simple websites:

```html
<script src="https://unpkg.com/@lunogram/js-sdk/lib/esm/index.js"></script>
```

## Getting Started

### Import the SDK

```typescript
// ES Modules
import { Client, BrowserClient } from '@lunogram/js-sdk'

// CommonJS
const { Client, BrowserClient } = require('@lunogram/js-sdk')
```

### Choose the Right Client

| Client | Use Case |
|--------|----------|
| `BrowserClient` | Web browsers - automatically persists anonymous ID |
| `Client` | Node.js - requires passing identifiers on each call |

### Initialize

```typescript
// Browser - user state is persisted automatically
const client = new BrowserClient({
  apiKey: "pk_your_public_api_key",
  urlEndpoint: "https://your-lunogram-instance.com/api"
})

// Node.js - stateless, pass identifiers on each call
const client = new Client({
  apiKey: "pk_your_public_api_key",
  urlEndpoint: "https://your-lunogram-instance.com/api"
})
```

For the CDN script tag, use the global `Lunogram` object:

```javascript
Lunogram.initialize({
  apiKey: "pk_your_public_api_key",
  urlEndpoint: "https://your-lunogram-instance.com/api"
})
```

## User Identification

### Identify

Associate the current user with your internal user ID and store user attributes.

```typescript
// Browser client - stores identity automatically
client.identify({
  externalId: "user_12345",
  email: "user@example.com",
  phone: "+1234567890",
  traits: {
    firstName: "John",
    lastName: "Smith",
    plan: "premium",
    signupDate: "2025-01-15"
  }
})

// Node.js - must pass identifiers each time
client.identify({
  anonymousId: "anon_abc123",
  externalId: "user_12345",
  email: "user@example.com",
  traits: {
    firstName: "John"
  }
})
```

**Parameters:**

| Field | Type | Description |
|-------|------|-------------|
| `externalId` | string | Your internal user ID |
| `anonymousId` | string | Anonymous ID (auto-generated in browser) |
| `email` | string | User's email address |
| `phone` | string | Phone in E.164 format (e.g., +1234567890) |
| `timezone` | string | IANA timezone (e.g., America/Chicago) |
| `locale` | string | Locale code (e.g., en, es-MX) |
| `traits` | object | Custom user attributes |

<Callout type="info">
Before calling `identify` with an `externalId`, all events are associated with an anonymous ID. Once identified, the anonymous profile is merged with the identified user.
</Callout>

### Anonymous to Identified Flow

```typescript
// 1. User visits site - anonymous ID auto-generated
client.track({ event: "Page Viewed", traits: { page: "/pricing" } })

// 2. User signs up - now we know who they are
client.identify({
  externalId: "user_12345",
  email: "new.user@example.com",
  traits: { plan: "trial" }
})

// 3. Future events are now tied to the identified user
client.track({ event: "Feature Used", traits: { feature: "dashboard" } })
```

## Event Tracking

### Track

Record user actions and events that can trigger journeys and update list memberships.

```typescript
// Browser client
client.track({
  event: "Product Purchased",
  traits: {
    productId: "prod_abc123",
    price: 49.99,
    currency: "USD",
    quantity: 2
  }
})

// Node.js - include user identifier
client.track({
  event: "Product Purchased",
  externalId: "user_12345",
  traits: {
    productId: "prod_abc123",
    price: 49.99
  }
})

// Global script
Lunogram.track({
  event: "Button Clicked",
  traits: {
    buttonId: "signup-cta",
    page: "/homepage"
  }
})
```

**Parameters:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `event` | string | Yes | Name of the event |
| `externalId` | string | No* | User identifier (required for Node.js) |
| `anonymousId` | string | No* | Anonymous identifier |
| `traits` | object | No | Event properties |

### Common Events

Here are some commonly tracked events:

```typescript
// E-commerce
client.track({ event: "Product Viewed", traits: { productId: "123", category: "shoes" } })
client.track({ event: "Added to Cart", traits: { productId: "123", quantity: 1 } })
client.track({ event: "Order Completed", traits: { orderId: "ord_456", total: 99.99 } })

// SaaS
client.track({ event: "Trial Started", traits: { plan: "pro" } })
client.track({ event: "Feature Used", traits: { feature: "reports" } })
client.track({ event: "Subscription Upgraded", traits: { from: "starter", to: "pro" } })

// Content
client.track({ event: "Article Read", traits: { articleId: "123", readTime: 240 } })
client.track({ event: "Video Watched", traits: { videoId: "456", percentComplete: 75 } })
```

## TypeScript Support

The SDK includes full TypeScript definitions:

```typescript
import { Client, BrowserClient, IdentifyParams, TrackParams } from '@lunogram/js-sdk'

interface UserTraits {
  firstName: string
  lastName: string
  plan: 'free' | 'starter' | 'pro'
}

const client = new BrowserClient({
  apiKey: "pk_xxx",
  urlEndpoint: "https://api.example.com"
})

// Type-safe identify
client.identify({
  externalId: "user_123",
  traits: {
    firstName: "John",
    lastName: "Doe",
    plan: "pro"
  } as UserTraits
})
```

## Error Handling

The SDK methods are asynchronous and return promises:

```typescript
try {
  await client.identify({
    externalId: "user_123",
    email: "user@example.com"
  })
  console.log("User identified successfully")
} catch (error) {
  console.error("Failed to identify user:", error)
}
```

## Best Practices

### 1. Initialize Early

Initialize the SDK as early as possible in your application:

```typescript
// React - in your root component
useEffect(() => {
  const client = new BrowserClient({
    apiKey: process.env.NEXT_PUBLIC_LUNOGRAM_KEY,
    urlEndpoint: process.env.NEXT_PUBLIC_LUNOGRAM_URL
  })
  window.lunogram = client
}, [])
```

### 2. Use Consistent Event Names

Establish naming conventions for your events:

```typescript
// Good - consistent format
"Order Completed"
"Product Viewed"
"Feature Used"

// Avoid - inconsistent
"order_completed"
"productViewed"
"FEATURE USED"
```

### 3. Include Relevant Context

Add useful context to events for better segmentation:

```typescript
client.track({
  event: "Subscription Upgraded",
  traits: {
    previousPlan: "starter",
    newPlan: "pro",
    billingCycle: "annual",
    discountApplied: true,
    source: "upgrade-modal"
  }
})
```

### 4. Identify Users Early

Identify users as soon as you know who they are:

```typescript
// After login
async function onLogin(user) {
  await client.identify({
    externalId: user.id,
    email: user.email,
    traits: {
      name: user.name,
      role: user.role
    }
  })
}
```

## Migration from Other SDKs

### From Segment

```typescript
// Segment
analytics.identify("user_123", { email: "user@example.com" })
analytics.track("Order Completed", { total: 99.99 })

// Lunogram
client.identify({ externalId: "user_123", email: "user@example.com" })
client.track({ event: "Order Completed", traits: { total: 99.99 } })
```

## Troubleshooting

### Events Not Appearing

1. Verify your API key is correct and is a public key (starts with `pk_`)
2. Check the network tab for failed requests
3. Ensure the `urlEndpoint` is correct

### User Not Identified

1. Confirm `identify` was called with a valid `externalId`
2. Check that the API key has access to the correct project

### CORS Errors

If you see CORS errors, verify that your domain is allowed in your Lunogram project settings.

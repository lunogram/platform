## Features

All client SDKs provide the following core functionality:

- **User Identification**: Associate users with your internal identifiers and track custom traits
- **Event Tracking**: Track user interactions and events to trigger journeys and update lists
- **Device Registration**: Register devices for push notification delivery
- **Deeplink Handling**: Unwrap and handle Lunogram tracking links for universal link support

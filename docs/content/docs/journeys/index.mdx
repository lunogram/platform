Journeys are automated workflows that deliver personalized communications at the right moment. Think of them as putting your messaging on auto-pilot: send messages, update user data, and trigger actions based on user behavior or schedules.

**Common use cases:**

- Welcome sequences for new users
- Cart abandonment reminders
- Re-engagement campaigns
- Milestone and achievement notifications
- Subscription renewal reminders

At its core, a journey is composed of **Steps**. You define how users enter through an **Entrance** step, then connect subsequent steps using a visual drag-and-drop editor.

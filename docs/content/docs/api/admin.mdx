# Admin API

The Admin API provides full programmatic access to manage all aspects of your Lunogram instance. This includes managing projects, campaigns, journeys, lists, users, and more.

## Authentication

Authentication to admin endpoints is handled via secret bearer API keys. You can [generate a new secret key](settings/api-keys) at any time in the portal.

To authenticate requests, set the `Authorization` header:

```
Authorization: Bearer sk_dbf68c87-e579-4dac-b083-77fed0294e67
```

<Callout type="warn">
Secret API keys have full access to your project data. Never expose them in client-side code or public repositories.
</Callout>

## Base URL

All Admin API endpoints are prefixed with `/api/admin`.

## Error Handling

All endpoints return errors in RFC 7807 Problem Details format:

```json
{
  "title": "Validation Error",
  "detail": "The 'name' field is required"
}
```

## Organizations

### Get Current Organization

Retrieves the organization for the authenticated admin.

```
GET /api/admin/organizations
```

**Response:** `200 OK`

```json
{
  "id": "uuid",
  "name": "My Organization",
  "created_at": "2025-01-01T00:00:00Z",
  "updated_at": "2025-01-01T00:00:00Z"
}
```

### Update Organization

Updates organization properties. Requires owner role.

```
PATCH /api/admin/organizations
```

**Body:**

```json
{
  "name": "Updated Organization Name"
}
```

## Projects

### List Projects

Retrieves all projects accessible to the authenticated admin.

```
GET /api/admin/projects?limit=20&offset=0&search=term
```

**Query Parameters:**
- `limit` (int) - Maximum results to return (default: 20)
- `offset` (int) - Number of results to skip
- `search` (string) - Filter by name

**Response:** `200 OK`

```json
{
  "data": [
    {
      "id": "uuid",
      "name": "My Project",
      "created_at": "2025-01-01T00:00:00Z"
    }
  ],
  "total": 1,
  "limit": 20,
  "offset": 0
}
```

### Create Project

Creates a new project.

```
POST /api/admin/projects
```

**Body:**

```json
{
  "name": "New Project"
}
```

**Response:** `201 Created`

### Get Project

Retrieves a specific project.

```
GET /api/admin/projects/{projectID}
```

### Update Project

Updates project properties.

```
PATCH /api/admin/projects/{projectID}
```

**Body:**

```json
{
  "name": "Updated Project Name"
}
```

## Campaigns

### List Campaigns

Retrieves campaigns for a project.

```
GET /api/admin/projects/{projectID}/campaigns?limit=20&offset=0
```

**Response:** `200 OK`

```json
{
  "data": [
    {
      "id": "uuid",
      "name": "Welcome Email",
      "type": "email",
      "status": "draft",
      "created_at": "2025-01-01T00:00:00Z"
    }
  ],
  "total": 1,
  "limit": 20,
  "offset": 0
}
```

### Create Campaign

Creates a new campaign.

```
POST /api/admin/projects/{projectID}/campaigns
```

**Body:**

```json
{
  "name": "Welcome Email",
  "type": "email",
  "provider_id": "uuid"
}
```

**Response:** `201 Created`

### Get Campaign

Retrieves a campaign with its templates.

```
GET /api/admin/projects/{projectID}/campaigns/{campaignID}
```

### Update Campaign

Updates campaign properties.

```
PATCH /api/admin/projects/{projectID}/campaigns/{campaignID}
```

**Body:**

```json
{
  "name": "Updated Campaign Name",
  "provider_id": "uuid"
}
```

### Duplicate Campaign

Creates a copy of a campaign with all its templates.

```
POST /api/admin/projects/{projectID}/campaigns/{campaignID}/duplicate
```

**Response:** `201 Created` - Returns the new campaign

### Get Campaign Users

Retrieves users who received a campaign.

```
GET /api/admin/projects/{projectID}/campaigns/{campaignID}/users?limit=20&offset=0
```

## Templates

### Create Template

Creates a new template for a campaign.

```
POST /api/admin/projects/{projectID}/campaigns/{campaignID}/templates
```

**Body:**

```json
{
  "locale": "en",
  "subject": "Welcome to {{company_name}}!",
  "html": "<html>...</html>",
  "text": "Plain text version"
}
```

### Get Template

Retrieves a specific template.

```
GET /api/admin/projects/{projectID}/campaigns/{campaignID}/templates/{templateID}
```

### Update Template

Updates template content.

```
PATCH /api/admin/projects/{projectID}/campaigns/{campaignID}/templates/{templateID}
```

### Delete Template

Deletes a template.

```
DELETE /api/admin/projects/{projectID}/campaigns/{campaignID}/templates/{templateID}
```

**Response:** `204 No Content`

## Journeys

### List Journeys

Retrieves journeys for a project.

```
GET /api/admin/projects/{projectID}/journeys?limit=20&offset=0
```

### Create Journey

Creates a new journey.

```
POST /api/admin/projects/{projectID}/journeys
```

**Body:**

```json
{
  "name": "Welcome Flow",
  "description": "Onboarding sequence for new users"
}
```

### Get Journey

Retrieves a specific journey.

```
GET /api/admin/projects/{projectID}/journeys/{journeyID}
```

### Update Journey

Updates journey properties.

```
PATCH /api/admin/projects/{projectID}/journeys/{journeyID}
```

**Body:**

```json
{
  "name": "Updated Journey Name",
  "status": "running"
}
```

### Delete Journey

Soft deletes a journey.

```
DELETE /api/admin/projects/{projectID}/journeys/{journeyID}
```

**Response:** `204 No Content`

### Get Journey Steps

Retrieves the step map (workflow definition) for a journey.

```
GET /api/admin/projects/{projectID}/journeys/{journeyID}/steps
```

**Response:** `200 OK`

```json
{
  "uuid-1": {
    "type": "entrance",
    "name": "Start",
    "data": {},
    "x": 0,
    "y": 0,
    "children": [{"external_id": "uuid-2"}]
  },
  "uuid-2": {
    "type": "action",
    "name": "Send Welcome Email",
    "data": {"campaign_id": "uuid"},
    "x": 0,
    "y": 200,
    "children": []
  }
}
```

### Set Journey Steps

Updates the journey workflow.

```
PUT /api/admin/projects/{projectID}/journeys/{journeyID}/steps
```

**Body:** Same format as Get Journey Steps response

### Publish Journey

Publishes the current draft version.

```
POST /api/admin/projects/{projectID}/journeys/{journeyID}/publish
```

### Create Journey Version

Creates a new version as a child of the current version.

```
POST /api/admin/projects/{projectID}/journeys/{journeyID}/version
```

### Duplicate Journey

Creates a complete copy of a journey.

```
POST /api/admin/projects/{projectID}/journeys/{journeyID}/duplicate
```

## Lists

### List Lists

Retrieves lists for a project.

```
GET /api/admin/projects/{projectID}/lists?limit=20&offset=0
```

### Create List

Creates a new list.

```
POST /api/admin/projects/{projectID}/lists
```

**Body:**

```json
{
  "name": "Active Users",
  "type": "dynamic",
  "rule": {
    "group": "and",
    "children": [
      {
        "path": "$.email",
        "operator": "is_set"
      }
    ]
  }
}
```

### Get List

Retrieves a specific list.

```
GET /api/admin/projects/{projectID}/lists/{listID}
```

### Update List

Updates list properties and rules.

```
PATCH /api/admin/projects/{projectID}/lists/{listID}
```

### Delete List

Soft deletes a list.

```
DELETE /api/admin/projects/{projectID}/lists/{listID}
```

### Get List Users

Retrieves users in a list.

```
GET /api/admin/projects/{projectID}/lists/{listID}/users?limit=20&offset=0
```

### Import List Users

Imports users to a static list from a CSV file.

```
POST /api/admin/projects/{projectID}/lists/{listID}/users
Content-Type: multipart/form-data
```

**Form Fields:**
- `file` - CSV file with `external_id` column

### Duplicate List

Creates a copy of a list.

```
POST /api/admin/projects/{projectID}/lists/{listID}/duplicate
```

## Users

### List Users

Retrieves users in a project.

```
GET /api/admin/projects/{projectID}/users?limit=20&offset=0&search=email
```

### Identify User

Creates or updates a user.

```
POST /api/admin/projects/{projectID}/users
```

**Body:**

```json
{
  "external_id": "user_123",
  "email": "user@example.com",
  "phone": "+1234567890",
  "timezone": "America/Chicago",
  "locale": "en",
  "data": {
    "first_name": "John",
    "last_name": "Doe"
  }
}
```

### Import Users

Bulk imports users from a CSV file.

```
POST /api/admin/projects/{projectID}/users/import
Content-Type: multipart/form-data
```

**Form Fields:**
- `file` - CSV file with `external_id` column and optional user attributes

### Get User

Retrieves a specific user.

```
GET /api/admin/projects/{projectID}/users/{userID}
```

### Update User

Updates user properties.

```
PATCH /api/admin/projects/{projectID}/users/{userID}
```

### Delete User

Deletes a user.

```
DELETE /api/admin/projects/{projectID}/users/{userID}
```

### Get User Events

Retrieves events for a user.

```
GET /api/admin/projects/{projectID}/users/{userID}/events?limit=20&offset=0
```

### Get User Subscriptions

Retrieves subscription states for a user.

```
GET /api/admin/projects/{projectID}/users/{userID}/subscriptions
```

### Update User Subscriptions

Updates subscription states.

```
PATCH /api/admin/projects/{projectID}/users/{userID}/subscriptions
```

### Get User Journeys

Retrieves journey entrances for a user.

```
GET /api/admin/projects/{projectID}/users/{userID}/journeys
```

## Events & Schemas

### List Event Schemas

Retrieves all events and their schema paths for a project.

```
GET /api/admin/projects/{projectID}/events/schema
```

**Response:**

```json
{
  "results": [
    {
      "name": "purchase_completed",
      "paths": [
        {"path": "$.product_id", "type": "string"},
        {"path": "$.amount", "type": "number"}
      ]
    }
  ]
}
```

### List User Schemas

Retrieves user data schema paths.

```
GET /api/admin/projects/{projectID}/users/schema
```

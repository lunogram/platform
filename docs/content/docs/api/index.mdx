Lunogram provides two types of APIs for different use cases:

<Cards>
  <Card title="Client API" href="/api/client">
    Public APIs for ingesting data from client applications. Used by SDKs for user identification, event tracking, and device registration.
  </Card>
  <Card title="Admin API" href="/api/admin">
    Private APIs for managing campaigns, triggering sends, and accessing platform data. Requires secret API keys.
  </Card>
</Cards>

## Authentication

Both APIs use Bearer token authentication. Include your API key in the `Authorization` header:

```
Authorization: Bearer YOUR_API_KEY
```

### API Key Types

- **Public Keys** (`pk_...`): Used with the Client API for data ingestion. Safe to use in client-side code.
- **Secret Keys** (`sk_...`): Used with the Admin API for full platform access. Keep these secure and never expose in client code.

Learn how to [create API keys](settings/api-keys) in your project settings.

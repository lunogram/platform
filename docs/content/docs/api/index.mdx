Lunogram provides two APIs for different use cases. Full interactive documentation is available at [console.lunogram.com/api](https://console.lunogram.com/api).

<Cards>
  <Card title="Client API" href="/api/client">
    Public API for ingesting data from client applications. Used by SDKs for
    user identification, event tracking, and device registration.
  </Card>
  <Card title="Management API" href="/api/management">
    Private API for managing campaigns, journeys, users, and platform
    configuration. Requires secret API keys.
  </Card>
</Cards>

## Authentication

Both APIs use Bearer token authentication. Include your API key in the `Authorization` header:

```
Authorization: Bearer YOUR_API_KEY
```

Each API key has a **role** that determines what it can access. Learn how to [create and manage auth methods](/settings/access) in your project settings.

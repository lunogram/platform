Lunogram provides official SDKs to integrate user tracking, event ingestion, and push notifications into your applications. All SDKs wrap the [Client API](/api/client) and handle authentication, request formatting, and error handling for you.

## Core functionality

Every SDK provides the same set of capabilities:

| Feature                     | Description                                                          |
| --------------------------- | -------------------------------------------------------------------- |
| **User identification**     | Create and update user profiles with custom attributes               |
| **Event tracking**          | Record user actions that trigger journeys and update list membership |
| **Organization management** | Group users into organizations with shared attributes and events     |
| **Scheduling**              | Create recurring or one-time schedules that emit events              |
| **Device registration**     | Register devices for push notification delivery                      |
| **Deeplink handling**       | Unwrap Lunogram tracking links for universal/app link support        |

## Authentication

SDKs authenticate with a **public API key** (prefixed `pk_`), which is safe to embed in client-side code: it can ingest data (users, events) but cannot read or modify anything.

For logged-in users who need to read their own data (inbox, preferences, profile), authenticate as a verified end user instead — either with a JWT from your own identity provider (a **trusted issuer**) or a short-lived **session** token minted by your backend. Each is scoped to that user's own data.

See [Access](/settings/access) to configure any of these auth methods in your project settings.

## Direct API access

If an SDK is not available for your language, you can integrate directly with the [Client API](/api/client). The API accepts standard JSON requests with a Bearer token and is straightforward to call from any HTTP client.

## Why Lunogram?

Customer engagement shouldn't require stitching together multiple tools or paying per-message fees. Lunogram gives you everything in one platform.

### Open Source, Your Way

Lunogram is fully open source. Run it yourself for complete control, or use Lunogram Cloud to get started in minutes.

## Connect Your App

Integrate Lunogram with a few lines of code:

```javascript
import Lunogram from '@lunogram/javascript-sdk';

const lunogram = new Lunogram({ apiKey: 'pk_your_key' });

// Identify users
lunogram.identify('user_123', { 
  email: 'user@example.com',
  plan: 'premium' 
});

// Track events
lunogram.track('Order Completed', { total: 99.99 });
```

SDKs available for [JavaScript](/clients/javascript), [iOS](/clients/ios), and [Android](/clients/android).

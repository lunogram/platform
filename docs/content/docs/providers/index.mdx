## How Providers Work

Lunogram uses [WebAssembly (WASM)](https://webassembly.org/) plugins for providers, powered by the [Extism](https://extism.org/) runtime. This architecture provides:

- **Sandboxed execution** - Providers run in isolated environments
- **Language flexibility** - Providers can be written in Go, Rust, or any WASM-compatible language
- **Hot reloading** - Add new providers without restarting Lunogram
- **Security** - Provider code cannot access the host system directly

## Creating Custom Providers

You can create custom providers for internal systems or unsupported services. See the [Architecture documentation](/advanced/architecture) for details on the WASM plugin system.

Example providers are available in the [modules/providers](https://github.com/lunogram/platform/tree/main/modules/providers) directory.

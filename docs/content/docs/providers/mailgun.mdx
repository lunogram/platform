# Mailgun

<Callout type="warn">
Mailgun provider support is coming soon. This documentation describes the planned functionality.
</Callout>

[Mailgun](https://www.mailgun.com/) is a powerful email API for sending, receiving, and tracking emails.

## Planned Features

- Email sending via Mailgun API
- Webhook support for bounces, complaints, and delivery status
- Domain verification and DKIM setup

## Setup (Coming Soon)

1. Create a [Mailgun account](https://signup.mailgun.com/)
2. Add and verify your sending domain
3. Generate an API key
4. Configure the integration in Lunogram

# Vonage (Nexmo)

<Callout type="warn">
Vonage provider support is coming soon. This documentation describes the planned functionality.
</Callout>

[Vonage](https://www.vonage.com/) (formerly Nexmo) provides communications APIs including SMS, voice, and video.

## Planned Features

- SMS sending via Vonage API
- Inbound webhook support for delivery status and opt-outs
- Phone number management

## Setup (Coming Soon)

1. Create a [Vonage account](https://dashboard.nexmo.com/sign-up)
2. Purchase a phone number with SMS capability
3. Get your API Key and API Secret
4. Configure the integration in Lunogram

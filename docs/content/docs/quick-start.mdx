This guide gets you from zero to a running self-hosted Lunogram instance in under 5 minutes.

<Callout type="info">
**Prerequisites:** Make sure you have [Docker](https://docs.docker.com/get-docker/) installed and running on your machine.
</Callout>

## Install & Run

```bash
git clone https://github.com/lunogram/platform.git
cd platform
docker compose up -d
```

That's it. Lunogram is now running at [http://localhost:8080](http://localhost:8080).

## Log In

Use the default credentials to access the dashboard:

| Field | Value |
|-------|-------|
| Email | `admin@localhost` |
| Password | `admin` |

<Callout type="warn">
Change these credentials before deploying to production. See [Configuration](/advanced/config) for details.
</Callout>

## What's Running

Docker Compose starts everything you need:

| Service | Purpose | Port |
|---------|---------|------|
| Lunogram | Main application | 8080 |
| PostgreSQL | Database | 5432 |
| Redis | Caching | 6379 |
| NATS | Event streaming | 4222 |

## Integrate Your App

Start tracking users and events:

```bash
npm install @lunogram/javascript-sdk
```

```javascript
import Lunogram from '@lunogram/javascript-sdk';

const lunogram = new Lunogram({
  apiKey: 'pk_your_public_key', // Get this from Project Settings > API Keys
  endpoint: 'http://localhost:8080/api'
});

lunogram.identify('user_123', { email: 'user@example.com' });
lunogram.track('Signed Up');
```

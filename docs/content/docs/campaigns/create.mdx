---
title: Create a Campaign
description: Set up a new campaign in Lunogram
---

Create a campaign by clicking **Create Campaign** in the Campaigns tab or through an action tile in a journey.

## Campaign Settings

### Name

Give your campaign a descriptive name. This appears in lists and reports throughout Lunogram.

### Integrations

Select one or more integrations (channels) to send your campaign through. Each integration connects to an external provider like Resend for email or Twilio for SMS.

| Channel | Description |
|---------|-------------|
| Email | Send HTML or plain text emails |
| SMS | Send text messages |
| Push | Send mobile push notifications |

You can select multiple integrations of the same type to send through different providers, or mix channels to reach users across multiple touchpoints.

<Callout type="info">
Before creating a campaign, make sure you have [configured at least one integration](/settings/integrations) in your project settings.
</Callout>

## Templates

Each campaign has templates for the locales configured in your project. When you create a campaign, Lunogram automatically creates a template for each locale, allowing you to customize the message content for different languages.

See [Templates](templates) for details on designing your message content and using personalization.

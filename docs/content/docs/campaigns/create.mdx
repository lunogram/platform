---
title: Create a Campaign
description: Set up a new campaign in Lunogram
---

Create a campaign by clicking **Create Campaign** in the Campaigns tab or through an action tile in a journey.

## Campaign Settings

When creating a campaign, first select the channel you want to use. Then configure the campaign name and integration on the setup page.

### Channel

Choose the channel for your campaign:

| Channel | Description                    |
| ------- | ------------------------------ |
| Email   | Send HTML or plain text emails |
| SMS     | Send text messages             |
| Push    | Send mobile push notifications |

### Integration

Select the integration to send your campaign through. Each integration connects to an external provider like Resend for email or Twilio for SMS. Only integrations matching the selected channel are shown.

<Callout type="info">
  Before creating a campaign, make sure you have [configured at least one
  integration](/integrations) in your project settings.
</Callout>

## Templates

Each campaign has templates for the locales configured in your project. When you create a campaign, Lunogram automatically creates a template for each locale, allowing you to customize the message content for different languages.

See [Templates](templates) for details on designing your message content and using personalization.

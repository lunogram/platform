Lunogram includes a comprehensive set of Handlebars helpers to transform and format data in your templates.

## Conditionals

### compare

Compare two values with an operator. Available operators: `==`, `===`, `!=`, `!==`, `<`, `>`, `<=`, `>=`.

```handlebars
{{#if (compare user.age ">=" 18)}}
  Welcome, adult user!
{{/if}}
```

### Equality Helpers

```handlebars
{{ eq a b }}   {{!-- equals --}}
{{ ne a b }}   {{!-- not equals --}}
{{ lt a b }}   {{!-- less than --}}
{{ gt a b }}   {{!-- greater than --}}
{{ lte a b }}  {{!-- less than or equal --}}
{{ gte a b }}  {{!-- greater than or equal --}}
```

### or / and

Combine multiple conditions:

```handlebars
{{#if (or (eq status "active") (eq status "trial"))}}
  Your account is active.
{{/if}}

{{#if (and (gte age 18) (eq country "US"))}}
  Eligible for US adult content.
{{/if}}
```

### numberFormat

Format numbers for display with locale-aware formatting:

```handlebars
{{!-- Decimal formatting --}}
{{ numberFormat 1234.56 "en-US" }}        {{!-- 1,234.56 --}}
{{ numberFormat 1234.56 "de-DE" }}        {{!-- 1.234,56 --}}

{{!-- Currency --}}
{{ numberFormat 19.99 "en-US" "currency" "USD" }}  {{!-- $19.99 --}}
{{ numberFormat 19.99 "de-DE" "currency" "EUR" }}  {{!-- 19,99 € --}}

{{!-- Percent --}}
{{ numberFormat 0.42 "en-US" "percent" }}  {{!-- 42% --}}
```

## Dates

### now

Get the current date/time:

```handlebars
{{ now }}                              {{!-- 2024-01-15 14:30:00 --}}
{{ now "MM/dd/yyyy" }}                 {{!-- 01/15/2024 --}}
{{ now "MMMM d, yyyy" "America/New_York" }}  {{!-- January 15, 2024 --}}
```

### dateFormat

Format a date value:

```handlebars
{{ dateFormat user.created_at "MMMM d, yyyy" }}
```

### Date Math

```handlebars
{{!-- Add time --}}
{{ addDate "2024-01-15" 7 "days" }}     {{!-- 2024-01-22 --}}
{{ addDate "2024-01-15" 1 "months" }}   {{!-- 2024-02-15 --}}

{{!-- Subtract time --}}
{{ subDate "2024-01-15" 7 "days" }}     {{!-- 2024-01-08 --}}

{{!-- Set specific component --}}
{{ setDate "2024-01-15" "days" 1 }}     {{!-- 2024-01-01 --}}
```

### nextDate

Find the next occurrence of a weekday:

```handlebars
{{ nextDate "now" "mo" }}  {{!-- Next Monday --}}
{{ nextDate "now" "fr" }}  {{!-- Next Friday --}}
```

Days: `mo`, `tu`, `we`, `th`, `fr`, `sa`, `su`

### dateDiff

Calculate the difference between dates:

```handlebars
{{ dateDiff "2024-01-15" "2024-01-01" "days" }}    {{!-- 14 --}}
{{ dateDiff "2024-01-15" "2024-01-01" "hours" }}   {{!-- 336 --}}
```

## URLs

```handlebars
{{!-- Encode for use in URLs --}}
{{ encodeURI "hello world" }}   {{!-- hello%20world --}}

{{!-- Decode URL-encoded strings --}}
{{ decodeURI "hello%20world" }} {{!-- hello world --}}

{{!-- Escape special characters --}}
{{ escape "<script>" }}         {{!-- &lt;script&gt; --}}
```

## Subscription Links

Generate links for managing subscriptions:

```handlebars
{{!-- One-click unsubscribe from this email type --}}
<a href="{{ unsubscribeEmailUrl }}">Unsubscribe</a>

{{!-- Link to preference center for all subscriptions --}}
<a href="{{ preferencesUrl }}">Manage preferences</a>
```

<Callout type="info">
Always include an unsubscribe link in marketing emails to comply with email regulations like CAN-SPAM and GDPR.
</Callout>

# Configuration

Lunogram is configured through environment variables. This page documents all available configuration options.

## General

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `NODE_ID` | string | (auto-generated) | No | Unique identifier for this node. If not set, generated from hostname hash. |
| `HTTP_ADDRESS` | string | `:8080` | No | Address and port for the HTTP server to listen on. |
| `DATABASE_MIGRATE` | boolean | `true` | No | Automatically run database migrations on startup. |

## Database

Lunogram uses PostgreSQL with four separate databases for different concerns.

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `RBAC_POSTGRES_URI` | string | `postgres://postgres:postgrespw@postgres:5432/openfga?sslmode=disable` | No | PostgreSQL connection URI for the OpenFGA (RBAC) database. |
| `POSTGRES_MANAGEMENT_URI` | string | `postgres://postgres:postgrespw@postgres:5432/management?sslmode=disable` | No | PostgreSQL connection URI for the management database. |
| `POSTGRES_SUBJECTS_URI` | string | `postgres://postgres:postgrespw@postgres:5432/subjects?sslmode=disable` | No | PostgreSQL connection URI for the subjects database. |
| `POSTGRES_JOURNEY_URI` | string | `postgres://postgres:postgrespw@postgres:5432/journey?sslmode=disable` | No | PostgreSQL connection URI for the journey database. |

**Example:**

```bash
RBAC_POSTGRES_URI=postgres://user:password@localhost:5432/openfga?sslmode=disable
POSTGRES_MANAGEMENT_URI=postgres://user:password@localhost:5432/management?sslmode=disable
POSTGRES_SUBJECTS_URI=postgres://user:password@localhost:5432/subjects?sslmode=disable
POSTGRES_JOURNEY_URI=postgres://user:password@localhost:5432/journey?sslmode=disable
```

## Redis

Redis is used for caching, distributed locks, and cluster coordination.

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `REDIS_ADDRESS` | string | `redis://127.0.0.1:6379` | No | Redis connection URL (supports `redis://` and `rediss://` for TLS). |
| `REDIS_KEY_PREFIX` | string | (empty) | No | Optional prefix for all Redis keys. Useful for sharing a Redis instance. |

**Example:**

```bash
REDIS_ADDRESS=redis://localhost:6379
REDIS_ADDRESS=rediss://user:password@redis.example.com:6380  # With TLS
```

## NATS

NATS JetStream is used for event processing and message queuing.

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `NATS_URL` | string | `nats://127.0.0.1:4222` | No | NATS server connection URL. |

**Example:**

```bash
NATS_URL=nats://localhost:4222
```

## Authentication

Lunogram supports multiple authentication methods.

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `AUTH_DRIVER` | string | - | Yes | Authentication driver to use: `basic` or `clerk`. |
| `AUTH_JWT_SECRET` | string | - | Yes | Secret key for signing JWT tokens. |
| `AUTH_JWKS_URL` | string | - | No | URL to fetch JSON Web Key Set for token validation. |
| `AUTH_TOKEN_LIFE` | duration | `24h` | No | How long authentication tokens remain valid. |

### Basic Authentication

For simple deployments with a single admin user.

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `AUTH_BASIC_EMAIL` | string | Yes | Email address for the admin user. |
| `AUTH_BASIC_PASSWORD` | string | Yes | Password for the admin user. |

**Example:**

```bash
AUTH_DRIVER=basic
AUTH_JWT_SECRET=your-secret-key-at-least-32-characters
AUTH_BASIC_EMAIL=admin@example.com
AUTH_BASIC_PASSWORD=secure-password
```

### Clerk Authentication

For production deployments with Clerk as the identity provider.

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `AUTH_CLERK_SECRET_KEY` | string | Yes | Clerk secret key from your dashboard. |
| `AUTH_CLERK_WEBHOOK_SECRET` | string | No | Webhook secret for Clerk user sync events. |

**Example:**

```bash
AUTH_DRIVER=clerk
AUTH_JWT_SECRET=your-secret-key
AUTH_CLERK_SECRET_KEY=sk_live_xxx
AUTH_CLERK_WEBHOOK_SECRET=whsec_xxx
```

## Cluster

Settings for distributed deployments with multiple nodes.

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `CLUSTER_RECONCILIATION_INTERVAL` | duration | `1m` | No | How often to reconcile cluster state. |
| `CLUSTER_LEADER_CAMPAIGN_INTERVAL` | duration | `5s` | No | How often nodes campaign for leadership. |
| `CLUSTER_HEARTBEAT_INTERVAL` | duration | `4s` | No | How often nodes send heartbeats. |

## Storage

Configuration for file uploads and block storage.

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `STORAGE_TYPE` | string | `local` | No | Storage backend: `local` or `s3`. |
| `STORAGE_MAX_UPLOAD_SIZE` | integer | `10485760` | No | Maximum upload size in bytes (default: 10MB). |

### Local Storage

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `STORAGE_LOCAL_UPLOAD_DIRECTORY` | string | `./uploads/documents` | No | Directory for storing uploaded files. |

### S3 Storage

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `STORAGE_S3_BUCKET` | string | Yes | S3 bucket name. |
| `STORAGE_S3_REGION` | string | Yes | AWS region. |
| `STORAGE_S3_ENDPOINT` | string | No | Custom S3 endpoint (for S3-compatible services). |
| `STORAGE_S3_ACCESS_KEY` | string | No | AWS access key (or use IAM roles). |
| `STORAGE_S3_SECRET_KEY` | string | No | AWS secret key (or use IAM roles). |

**Example:**

```bash
STORAGE_TYPE=s3
STORAGE_S3_BUCKET=my-lunogram-bucket
STORAGE_S3_REGION=us-east-1

# For S3-compatible services like MinIO
STORAGE_S3_ENDPOINT=http://minio:9000
STORAGE_S3_ACCESS_KEY=minioadmin
STORAGE_S3_SECRET_KEY=minioadmin
```

## HTTP Server

Advanced HTTP server configuration.

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `READ_HEADER_TIMEOUT` | duration | `5s` | No | Maximum time to read request headers. |
| `READ_TIMEOUT` | duration | `5s` | No | Maximum time to read entire request. |
| `IDLE_TIMEOUT` | duration | `5s` | No | Maximum time to wait for next request. |
| `WRITE_TIMEOUT` | duration | `10s` | No | Maximum time to write response. |
| `MAX_HEADER_BYTES` | integer | `1048576` | No | Maximum header size in bytes (default: 1MB). |

## CSRF Protection

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `CSRF_ENABLED` | boolean | `true` | No | Enable CSRF protection. |
| `CSRF_SECRET` | string | (auto-generated) | No | Secret for CSRF token generation. |
| `CSRF_TOKEN_LENGTH` | integer | `32` | No | Length of CSRF tokens in bytes. |
| `CSRF_COOKIE_NAME` | string | `csrf_token` | No | Name of the CSRF cookie. |
| `CSRF_HEADER_NAME` | string | `X-CSRF-Token` | No | Name of the CSRF header. |
| `CSRF_COOKIE_SECURE` | boolean | `true` | No | Require HTTPS for CSRF cookie. |
| `CSRF_COOKIE_HTTP_ONLY` | boolean | `true` | No | HTTP-only CSRF cookie. |
| `CSRF_COOKIE_SAME_SITE` | string | `strict` | No | SameSite attribute: `strict`, `lax`, `none`. |
| `CSRF_TRUSTED_ORIGINS` | string[] | - | No | Comma-separated list of trusted origins. |

## WASM

Configuration for WebAssembly-based provider plugins.

| Key | Type | Default | Required | Description |
|-----|------|---------|----------|-------------|
| `WASM_CALL_TIMEOUT` | duration | `30s` | No | Maximum time for WASM function calls. |

## Example Configuration

Here's a complete example for a production deployment:

```bash
# General
NODE_ID=node-1
HTTP_ADDRESS=:8080

# Database
RBAC_POSTGRES_URI=postgres://lunogram:password@postgres:5432/openfga?sslmode=require
POSTGRES_MANAGEMENT_URI=postgres://lunogram:password@postgres:5432/management?sslmode=require
POSTGRES_SUBJECTS_URI=postgres://lunogram:password@postgres:5432/subjects?sslmode=require
POSTGRES_JOURNEY_URI=postgres://lunogram:password@postgres:5432/journey?sslmode=require

# Redis
REDIS_ADDRESS=redis://redis:6379

# NATS
NATS_URL=nats://nats:4222

# Authentication
AUTH_DRIVER=clerk
AUTH_JWT_SECRET=your-production-secret-key-minimum-32-chars
AUTH_CLERK_SECRET_KEY=sk_live_xxx
AUTH_CLERK_WEBHOOK_SECRET=whsec_xxx

# Storage
STORAGE_TYPE=s3
STORAGE_S3_BUCKET=lunogram-uploads
STORAGE_S3_REGION=us-east-1

# Cluster
CLUSTER_RECONCILIATION_INTERVAL=1m
CLUSTER_LEADER_CAMPAIGN_INTERVAL=5s
CLUSTER_HEARTBEAT_INTERVAL=4s
```

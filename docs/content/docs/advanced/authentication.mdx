# Authentication

Lunogram supports multiple authentication methods:

- **Basic** - Simple email/password authentication (default)
- **Clerk** - Enterprise SSO with [Clerk](https://clerk.com/)

## Configuration

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `AUTH_DRIVER` | `basic` \| `clerk` | `basic` | Authentication provider to use |
| `AUTH_JWT_SECRET` | string | | Secret key for signing JWT tokens |
| `AUTH_TOKEN_LIFE` | duration | `24h` | How long authentication tokens are valid |
| `AUTH_JWKS_URL` | string | | JWKS endpoint URL (for Clerk) |

## Basic Authentication

Basic authentication is the default method, allowing a single admin user configured via environment variables. This is suitable for evaluation, development, or single-user deployments.

### Configuration

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `AUTH_DRIVER` | `basic` | No | Set to `basic` (or omit, as it's the default) |
| `AUTH_BASIC_EMAIL` | string | Yes | Admin user email |
| `AUTH_BASIC_PASSWORD` | string | Yes | Admin user password |

### Example

```bash
AUTH_DRIVER=basic
AUTH_BASIC_EMAIL=admin@example.com
AUTH_BASIC_PASSWORD=your-secure-password
AUTH_JWT_SECRET=your-jwt-secret-key-min-32-chars
```

<Callout type="warning">
Basic authentication only supports a single admin user. For multi-user access and enterprise SSO, use Clerk authentication.
</Callout>

## Clerk Authentication

[Clerk](https://clerk.com/) provides enterprise-grade authentication with support for:

- Multiple users and organizations
- Social login (Google, GitHub, etc.)
- SAML SSO
- Multi-factor authentication
- User management dashboard

### Configuration

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `AUTH_DRIVER` | `clerk` | Yes | Enable Clerk authentication |
| `AUTH_CLERK_SECRET_KEY` | string | Yes | Your Clerk secret key |
| `AUTH_CLERK_WEBHOOK_SECRET` | string | No | Webhook signing secret for user sync |
| `AUTH_JWKS_URL` | string | Yes | Clerk JWKS endpoint URL |

### Example

```bash
AUTH_DRIVER=clerk
AUTH_CLERK_SECRET_KEY=sk_live_xxxxx
AUTH_CLERK_WEBHOOK_SECRET=whsec_xxxxx
AUTH_JWKS_URL=https://your-app.clerk.accounts.dev/.well-known/jwks.json
```

### User Synchronization

When webhooks are configured, Lunogram automatically:

- Creates admin users when they sign up in Clerk
- Updates user information when profiles change
- Removes access when users are deleted

This ensures your Lunogram admin users stay in sync with your Clerk user directory.

## Troubleshooting

### "Invalid credentials" with Basic Auth

1. Verify `AUTH_BASIC_EMAIL` and `AUTH_BASIC_PASSWORD` are set correctly
2. Check for trailing whitespace in environment variables
3. Ensure you're using the correct email format

### "Token verification failed"

1. Verify `AUTH_JWKS_URL` is correct and accessible

[SendGrid](https://sendgrid.com/) (owned by Twilio) provides email delivery services for both transactional and marketing emails.

## Planned Features

- Email sending via SendGrid API
- Webhook support for bounces, spam reports, and delivery status
- Sender verification

## Setup (Coming Soon)

1. Create a [SendGrid account](https://signup.sendgrid.com/)
2. Verify your sender identity
3. Create an API key
4. Configure the integration in Lunogram

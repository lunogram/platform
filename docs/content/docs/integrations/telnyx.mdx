[Telnyx](https://telnyx.com/) is a communications platform offering SMS, voice, and connectivity services.

## Planned Features

- SMS sending via Telnyx API
- Inbound webhook support for delivery status and opt-outs
- Phone number management

## Setup (Coming Soon)

1. Create a [Telnyx account](https://telnyx.com/)
2. Purchase a phone number with SMS capability
3. Get your API key
4. Configure the integration in Lunogram

[Plivo](https://www.plivo.com/) is a cloud communications platform offering SMS, voice, and WhatsApp messaging.

## Planned Features

- SMS sending via Plivo API
- Inbound webhook support for delivery status and opt-outs
- Phone number management

## Setup (Coming Soon)

1. Create a [Plivo account](https://www.plivo.com/)
2. Purchase a phone number with SMS capability
3. Get your Auth ID and Auth Token
4. Configure the integration in Lunogram

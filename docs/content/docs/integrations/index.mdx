## How Integrations Work

Lunogram uses [WebAssembly (WASM)](https://webassembly.org/) plugins for integrations, powered by the [Extism](https://extism.org/) runtime. This architecture provides:

- **Sandboxed execution** - Integrations run in isolated environments
- **Language flexibility** - Integrations can be written in Go, Rust, or any WASM-compatible language
- **Hot reloading** - Add new integrations without restarting Lunogram
- **Security** - Integration code cannot access the host system directly

## Creating Custom Integrations

You can create custom integrations for internal systems or unsupported services. Examples are available in the [modules/providers](https://github.com/lunogram/platform/tree/main/modules/providers) directory.
